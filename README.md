# Ethernet to USB 3.2 Adapter

This project consists of the hardware design of a USB 3.2 to Gigabit Ethernet adapter based on the Microchip LAN7800 controller. 
The objective was to develop a compact, manufacturable, and high-speed PCB following industry best practices for signal integrity, power distribution, and PCB layout.

### Features
<ul>
  <li>USB 3.2 Gen 1 (5 Gbps)</li>
  <li>Gigabit Ethernet</li>
  <li>Microchip LAN7800</li>
  <li>4-Layer PCB</li>
  <li>Controlled Impedance Routing</li>
  <li>Differential pair length matching (5 Gbps)</li>
</ul>
